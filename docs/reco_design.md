# Архітектура рекомендаційного модуля Domain Knowledge Hub (Результат 1)

## 1. Реалізовані моделі ранжування (reco/recommender.py)
1. Popularity Baseline - ранжування продуктів за частотою взаємодій у навчальній вибірці train.
2. Graph Path Recommender - рекомендації на основі семантичних шляхів онтології: UserSegment -> hasMCC -> MCC_Code -> eligibleFor -> FinProduct.
3. Embedding kNN Recommender - косинусна подібність TF-IDF векторів описів продуктів до усередненого вектора історії покупок користувача.
4. Hybrid RRF (Reciprocal Rank Fusion) - зважене обʼєднання списків графа (w_graph = 0.65) та embeddings (w_emb = 0.35, k_rrf = 10).

## 2. Фільтри якості та прав доступу (Quality & Governance Gate)
* Перевірка верифікації (verified == True): відсіює чернетки без підтвердженого provenance (Unverified_Crypto).
* Перевірка свіжості (fresh_2026 == True): виключає архівні тарифи 2025 року (Old_2025_Tariff).
* Контроль прав доступу (sensitivity == "public"): блокує показ закритих продуктів (Restricted_Private) без відповідного рівня доступу.

## 3. Проєктні обмеження (3 обмеження)
1. Векторний профіль користувача базується на TF-IDF описах продуктів і не враховує часове затухання старих транзакцій.
2. Графові шляхи обмежені глибиною 2 кроки (Segment -> MCC -> FinProduct) для гарантії затримки < 15 мс.
3. Рекомендації мають довідковий характер і перед оформленням кредитного ліміту проходять додатковий банківський скоринг.
