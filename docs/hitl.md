# Політика Human-in-the-Loop (HITL) та журнал аудиту (Результат 5)

## 1. Класифікація ризиків при записі знань (agent/propose_fact.py)
* Низький ризик (low): додавання нової сутності валідного класу (наприклад, TwoTower_Model) з підтвердженим provenance (DOC-XX) без зміни фінансових лімітів -> автоматичне схвалення (auto_approved).
* Середній ризик (medium): оновлення фінансового порогу або тарифу в допустимому діапазоні (наприклад, maxLimit = 80000) -> обовʼязкове підтвердження людиною (human_approved).
* Високий ризик (high): відсутній provenance, невідомий клас або вихід значення за допустимі межі (maxLimit = -9999) -> автоматичне відхилення (rejected_high_risk).

## 2. Журнал аудиту та метрики HITL (logs/hitl_audit.jsonl)
* Загальна кількість запитів на запис: 3.
* Частка схвалених змін (Approval Rate): 66.7% (2/3: 1 автоматично, 1 схвалено ревʼюером).
* Частка відхилених ризикових змін (Rejection Rate): 33.3% (1/3).
* Середній час схвалення людиною (Mean Review Time): 18.4 секунди.
