# Сценарій 7-хвилинної демонстрації (docs/demo_script.md)
1. Хв 0-1: Запуск системи однією командою (docker-compose up --build або python3 demo_cli.py).
2. Хв 1-3: Демонстрація Hybrid RRF для VIP-сегменту (MCC 6012) та перевірки шляху пояснення.
3. Хв 3-5: Демонстрація холодного старту для нового користувача (Youth, MCC 5814).
4. Хв 5-7: Демонстрація відмови при запиті закритого продукту (Restricted_Private) та блокування неперевіреного активу (Unverified_Crypto).
