# Офлайн-оцінювання рекомендаційної системи (Результат 2)

## 1. Протокол часового розбиття (Temporal Split без витоку з майбутнього)
* Вибірка: 60 користувачів, 240 взаємодій у сегментах VIP, Mass та Youth.
* Train (2026-10-10 .. 2026-10-11): історичні взаємодії користувачів для побудови профілю та частот популярності.
* Test (2026-11-15 .. 2026-11-16): майбутні взаємодії користувачів, суворо ізольовані від навчання.

## 2. Обґрунтування вибору кращої конфігурації
* Обрано конфігурацію Hybrid RRF (w_graph = 0.65, w_emb = 0.35), яка поєднує точність графових шляхів онтології з високим покриттям каталогу (Coverage) та новизною (Novelty) векторного пошуку embeddings, забезпечуючи найвищий компроміс між точністю ранжування nDCG@10 та різноманіттям рекомендацій.
